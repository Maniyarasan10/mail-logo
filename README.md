# mail-logo

**Problem Solving Mind** — a minimal static site that displays the project logo.

## Contents

| File | Description |
| --- | --- |
| `index.html` | Page markup, inline styles, centered logo on a light background |
| `logo.svg` | Scalable logo artwork |

## Live site

Published with GitHub Pages from the `main` branch:

<https://maniyarasan10.github.io/mail-logo/>

## Local preview

No build step or dependencies. Open `index.html` directly in a browser, or serve the
folder locally:

```bash
npx serve .
```

## Deploy

Pushes to `main` are published automatically by the GitHub Pages workflow in
`.github/workflows/pages.yml`.
